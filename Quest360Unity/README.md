# TENDA Quest 360

Projeto Unity nativo para Meta Quest 2/3/3S.

## Abrir e gerar o APK

1. Instale Unity 2022.3 LTS com Android Build Support, SDK/NDK e OpenJDK.
2. Abra esta pasta no Unity Hub.
3. Configure a plataforma Android e o XR Plug-in Management/OpenXR para Oculus/Meta Quest.
4. Abra uma cena vazia e faça Build And Run para um Quest conectado por USB.

O app carrega os panoramas de `Assets/StreamingAssets/Panoramas` e usa os controles:

- X: próximo ambiente
- Y: sair
- A/B: zoom
